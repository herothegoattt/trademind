# TradeMind AI - Структура проекта

## Обзор

Проект организован по модульному принципу для удобной навигации и масштабируемости.

## Описание модулей

### `app/main.py`
- Точка входа FastAPI приложения
- Инициализация приложения с настройками
- Подключение роутеров
- Корневой эндпоинт `/`

### `app/api/routes.py`
- Все API эндпоинты
- `/api/v1/health` - проверка здоровья API
- `/api/v1/analyze` - основной эндпоинт анализа решений
- Обработка ошибок и валидация запросов

### `app/schemas/decision.py`
- **Decision**: Модель входящего решения/сделки
  - Поддержка 4 режимов: trading, investing, business, personal
  - Режим-специфичные поля данных
- **Insight**: Модель результата анализа
  - Технические и психологические паттерны
  - Рекомендации и стратегии предотвращения ошибок
  - Оценки качества решения и риска

### `app/services/analysis.py`
- **AnalysisService**: Сервис анализа решений
  - `analyze_decision()` - главный метод анализа
  - Режим-специфичные методы:
    - `_analyze_trading()` - анализ торговых сделок
    - `_analyze_investing()` - анализ инвестиций
    - `_analyze_business()` - анализ бизнес-решений
    - `_analyze_personal()` - анализ личных решений
  - `_build_insight()` - построение результата анализа

### `app/core/config.py`
- **Settings**: Конфигурация приложения
  - Название, версия, описание
  - Настройки API
  - Поддержка переменных окружения через `.env`

## Режимы работы

### 1. Trading (Основной)
- **Поля**: `trade_data`
- **Анализ**: сделки, риск, эмоции, стратегия
- **Паттерны**: эмоциональная торговля, риск-менеджмент

### 2. Investing
- **Поля**: `investment_data`
- **Анализ**: долгосрочные решения, вход/выход, переоценка риска, bias
- **Паттерны**: overconfidence, confirmation bias

### 3. Business
- **Поля**: `business_data`
- **Анализ**: найм, запуски, фейлы, решения под стрессом
- **Паттерны**: стресс-решения, процесс принятия решений

### 4. Personal
- **Поля**: `personal_data`
- **Анализ**: важные жизненные решения, выбор, ошибки, привычки
- **Паттерны**: повторяющиеся ошибки, формирование привычек

## Как найти информацию

### Поиск по функциональности:
- **API эндпоинты** → `app/api/routes.py`
- **Модели данных** → `app/schemas/decision.py`
- **Логика анализа** → `app/services/analysis.py`
- **Настройки** → `app/core/config.py`

### Поиск по режиму:
- **Trading логика** → `app/services/analysis.py` → `_analyze_trading()`
- **Investing логика** → `app/services/analysis.py` → `_analyze_investing()`
- **Business логика** → `app/services/analysis.py` → `_analyze_business()`
- **Personal логика** → `app/services/analysis.py` → `_analyze_personal()`

## Расширение проекта

### Добавление нового эндпоинта:
1. Добавить функцию в `app/api/routes.py`
2. При необходимости создать новую схему в `app/schemas/`

### Добавление нового режима:
1. Обновить `Decision.mode` в `app/schemas/decision.py`
2. Добавить метод `_analyze_<mode>()` в `app/services/analysis.py`
3. Обновить роутинг в `analyze_decision()`

### Добавление новой бизнес-логики:
1. Создать новый сервис в `app/services/`
2. Импортировать и использовать в `app/api/routes.py`
